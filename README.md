# Zuri para computador

App de computador da Zuri (antes chamada Zarpa), para Windows e Mac. Ele abre o painel da Zuri, e o login é o mesmo do site.

## Baixar

| Computador | Arquivo |
|---|---|
| Windows | [Zuri-Windows.exe](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest/download/Zuri-Windows.exe) |
| Mac com chip Apple (M1, M2, M3…) | [Zuri-Mac-chip-Apple.dmg](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest/download/Zuri-Mac-chip-Apple.dmg) |
| Mac com Intel | [Zuri-Mac-Intel.dmg](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest/download/Zuri-Mac-Intel.dmg) |

Para saber qual é o seu Mac: menu Apple → Sobre Este Mac. Lá aparece "Chip Apple" ou "Processador Intel".

Os links sempre baixam a versão mais nova. Os links antigos, com o nome Zarpa, também baixam a Zuri. Os outros arquivos da [página de versões](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest) são usados pelas atualizações e não precisam ser baixados.

## Na primeira vez, autorize o programa

**Windows**

1. Se o navegador perguntar sobre o arquivo, escolha "Manter".
2. Abra o arquivo baixado.
3. O Windows vai pedir a sua autorização: na tela azul, clique em "Mais informações" e depois em "Executar assim mesmo".
4. Pronto: a Zuri instala sozinha e abre.

**Mac** ([vídeo de 1 minuto mostrando cada passo](https://app.agente-de-turismo-veltrix.com.br/videos/como-instalar-zarpa-mac.mp4))

1. Abra o arquivo baixado e arraste a Zuri para a pasta Aplicativos.
2. Abra a Zuri. O Mac vai pedir a sua autorização: clique em "OK" (não em "Mover para o Lixo").
3. Vá em Ajustes do Sistema → Privacidade e Segurança, role até "Segurança" e clique em "Abrir Mesmo Assim". Se aparecer outra janela, clique de novo em "Abrir Mesmo Assim" e confirme com a senha do Mac.
4. Pronto: das próximas vezes ela abre direto.

## Atualizações

- **Novidades do painel:** chegam sozinhas.
- **Programa no Windows:** a versão nova baixa sozinha. Aparece o botão "Atualizar" no alto da janela, e ela entra quando você fechar o app.
- **Programa no Mac:** aparece o botão "Atualizar" no alto da janela. Ele abre o download da versão nova. Feche o app (Cmd+Q), abra o arquivo baixado e arraste a Zuri para Aplicativos. Na primeira vez que abrir a versão nova, o Mac pede a autorização de novo (passos 2 e 3 acima).

## De Zarpa para Zuri

O app mudou de nome, mas é o mesmo, e você continua conectado.

- **Windows:** a atualização troca o nome e o ícone sozinha.
- **Mac:** depois de instalar a Zuri, ao abrir pela primeira vez, a Zarpa antiga vai para o Lixo. Se ela estava no Dock, tire o ícone antigo e coloque o da Zuri.
