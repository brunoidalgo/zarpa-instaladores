# Zarpa para computador

Instaladores do app de computador da Zarpa, para uso interno da Agência Veltrix. O app abre o painel da Zarpa, e o login é o mesmo do site.

## Baixar

Última versão: **https://github.com/brunoidalgo/zarpa-instaladores/releases/latest**

| Computador | Arquivo |
|---|---|
| Windows | `Zarpa-Setup-<versão>.exe` |
| Mac com chip Apple (M1, M2, M3…) | `Zarpa-<versão>-arm64.dmg` |
| Mac com Intel | `Zarpa-<versão>-x64.dmg` |

Para saber qual é o seu Mac: menu Apple → Sobre Este Mac. Se aparecer "Chip Apple", é o arm64; se aparecer "Processador Intel", é o x64.

Os arquivos `.zip`, `.yml` e `.blockmap` são usados pelas atualizações. Não precisa baixar.

## Primeira vez

- **Windows:** se aparecer "O Windows protegeu o computador", clique em "Mais informações" e depois em "Executar assim mesmo".
- **Mac:**
  1. Abra o `.dmg` e arraste a Zarpa para a pasta Aplicativos.
  2. Abra a Zarpa. O Mac vai avisar que não conseguiu verificar o app: clique em "Concluído".
  3. Vá em Ajustes do Sistema → Privacidade e Segurança, role até o fim e clique em "Abrir Mesmo Assim". Confirme com a senha do Mac.

## Atualizações

- **Novidades do painel:** chegam sozinhas.
- **Windows:** quando houver versão nova do app, ela é baixada sozinha. Aparece o botão "Atualizar" no alto da janela, e a versão nova entra quando você fechar o app.
- **Mac:** aparece o botão "Atualizar" no alto da janela. Ele abre o download da versão nova. Feche a Zarpa e arraste a nova para Aplicativos, escolhendo "Substituir".
