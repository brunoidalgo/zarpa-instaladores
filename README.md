# Zarpa para computador

App de computador da Zarpa, para Windows e Mac. Ele abre o painel da Zarpa, e o login é o mesmo do site.

## Baixar

| Computador | Arquivo |
|---|---|
| Windows | [Zarpa-Windows.exe](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest/download/Zarpa-Windows.exe) |
| Mac com chip Apple (M1, M2, M3…) | [Zarpa-Mac-chip-Apple.dmg](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest/download/Zarpa-Mac-chip-Apple.dmg) |
| Mac com Intel | [Zarpa-Mac-Intel.dmg](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest/download/Zarpa-Mac-Intel.dmg) |

Para saber qual é o seu Mac: menu Apple → Sobre Este Mac. Lá aparece "Chip Apple" ou "Processador Intel".

Os links sempre baixam a versão mais nova. Os outros arquivos da [página de versões](https://github.com/brunoidalgo/zarpa-instaladores/releases/latest) são usados pelas atualizações e não precisam ser baixados.

## Na primeira vez, autorize o programa

**Windows**

1. Se o navegador perguntar sobre o arquivo, escolha "Manter".
2. Abra o arquivo baixado.
3. O Windows vai pedir a sua autorização: na tela azul, clique em "Mais informações" e depois em "Executar assim mesmo".
4. Pronto: a Zarpa instala sozinha e abre.

**Mac**

1. Abra o arquivo baixado e arraste a Zarpa para a pasta Aplicativos.
2. Abra a Zarpa. O Mac vai pedir a sua autorização: clique em "Concluído" (não em "Mover para o Lixo").
3. Vá em Ajustes do Sistema → Privacidade e Segurança, role até o fim e clique em "Abrir Mesmo Assim". Confirme com a senha do Mac.
4. Pronto: das próximas vezes ela abre direto.

## Atualizações

- **Novidades do painel:** chegam sozinhas.
- **Programa no Windows:** a versão nova baixa sozinha. Aparece o botão "Atualizar" no alto da janela, e ela entra quando você fechar o app.
- **Programa no Mac:** aparece o botão "Atualizar" no alto da janela. Ele abre o download da versão nova. Feche a Zarpa e arraste a nova para Aplicativos, escolhendo "Substituir".
